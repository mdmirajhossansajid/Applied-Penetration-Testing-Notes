nslookup (Smpaly check about Domain)
         Find an IP Address (A Record): Retrieves the IP address for a specific domain.
                   >nslookup example.com
         Reverse DNS Lookup: Finds the domain name associated with an IP address.
                   >nslookup 192.168.1.1
         Look up Mail Servers (MX Records): Identifies servers responsible for receiving email.
                   >nslookup -type=mx example.com
         Query Specific DNS Records: Use the -type or -q flag to find records like ns (Name Server), txt (Text), or soa (Start of Authority).
                   >nslookup -type=ns example.com
         Use a Specific DNS Server: Query a specific server (e.g., Google's 8.8.8.8) instead of your default local server.
                   >nslookup example.com 8.8.8.8
         Enable Debug Mode: View detailed information about the query and response packets.
                   >nslookup -debug example.com
         Set record type: set type=mx (Looking Email Server Mxtoolbox Records)
         Set record type: set type=NS (Looking Name Server)
